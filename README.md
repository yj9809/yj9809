# 윤제영 | 게임 클라이언트 개발자

**C++와 Unreal Engine으로 플레이어의 조작, 게임의 규칙, 화면의 피드백을 연결합니다.**

콘솔 게임에서 충돌·상태 전환·경로 탐색을 직접 구현하고, Unreal 프로젝트에서 액션 전투와 UI/HUD로 개발 범위를 넓혔습니다. 동작이 어긋나는 조건을 찾아 수정하고, 데이터와 책임을 나눠 팀원이 이어서 작업할 수 있는 구조를 만드는 데 집중합니다.

## 프로젝트

### BladeZ — 액션 전투와 입력 처리
**UE5 · C++ · 5인 팀 / 플레이어 이동·카메라·전투 담당**

- 빠르게 움직이는 무기의 이전·현재 위치를 다중 Sphere Trace로 연결해 프레임 사이 판정 공백을 보완했습니다.
- 최신 입력 하나를 저장하고 전환 Notify에서 소비하는 콤보를 구현했습니다. 공격 분기·수치·피드백은 DataAsset으로 분리하고, 공통 대미지 이벤트로 팀원의 피격 반응과 연결했습니다.

[코드](https://github.com/yj9809/BladeZ) · [구현 과정과 검증](https://www.notion.so/3678d1fa63aa8168b98ac79c315019c9)

### Pragmata — 게임 상태를 전달하는 UI/HUD
**UE5 · C++ · UMG · MVVM / 5인 팀, UI/HUD 전담**

- 액션 시스템 구현 경험을 바탕으로 UI/HUD 전담을 직접 제안했습니다. 해킹 퍼즐, 상태별 게이지 연출, 획득량 합산 알림, 강화 메뉴의 홀드 입력을 구현했습니다.
- 공유 HUD·해킹에는 ViewModel, 적 HP에는 컴포넌트 이벤트 직접 구독을 적용했습니다. 시스템 담당자와 필요한 값·이벤트·호출 시점을 조율하고 연결 가이드로 남겼습니다.

[코드](https://github.com/yj9809/Pragmata_2P_Clean) · [담당 구현과 협업](https://www.notion.so/39e8d1fa63aa8162a320c32c955cdf7e)

### ASCII Defense — 경로 탐색과 부하 분산
**C++ · Console / 개인 프로젝트**

- A*의 선형 탐색을 `priority_queue`와 2D 배열로 바꾸고, 타워 배치에 영향받은 적의 경로 재계산을 큐로 분산했습니다.
- 임시 격자에서 경로가 유지되는지 확인해 타워 배치를 검증하고, 여러 적의 이동 충돌을 처리했습니다.

[코드](https://github.com/yj9809/ASCIIDefense) · [탐색 구조와 측정 기록](https://www.notion.so/3218d1fa63aa80439f14cb0b69ad034f)

### Console Mario — 충돌·상태·게임 루프
**C++ · Console / 개인 프로젝트**

- X/Y축 분리 충돌과 플레이어 상태 전환을 구현하고, 이동 플랫폼·스크롤 카메라·3개 스테이지를 클리어까지 연결했습니다.
- 천장 충돌과 착지 시 상태 전이를 정리하고, 레벨 전환 시 충돌 리스너와 콜라이더를 해제하도록 객체 수명주기를 다듬었습니다.

[코드](https://github.com/yj9809/ConsoleMario) · [문제 해결 과정](https://www.notion.so/aa78d1fa63aa8334890901bae1066394) · [플레이 영상](https://www.youtube.com/watch?v=IOTGzlAueAQ)

## 개발할 때 중요하게 생각하는 것

- **원인과 재현 조건:** 증상에서 출발해 입력, 상태 전환, 호출 순서를 따라가며 원인을 확인합니다.
- **필요에 맞는 구조:** 상태를 모으는 범위와 수정 흐름에 맞춰 컴포넌트·데이터·UI의 책임을 나눕니다.
- **연결할 수 있는 문서:** 구현한 범위, 필요한 값과 이벤트, 호출 시점과 검증 조건을 코드와 함께 남깁니다.

**주요 기술:** C++ · STL · Unreal Engine 5 · Blueprint · UMG · MVVM(FieldNotify) · Git
